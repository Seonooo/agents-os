# Mastra — Skills

## 1줄
Mastra가 자체 지식·스크립트를 "Skills 표준" 패키지로 배포해 Claude Code·Cursor·Codex 등에서 동일하게 사용할 수 있게 한 설치·운영 가이드.

## 핵심
- Skills = "에이전트가 발견하고 활용할 수 있는 지침·스크립트·리소스 모음"
- npm/pnpm/Yarn/Bun 설치 → `skills update mastra`로 최신 유지
- Skills 표준 지원 IDE/에이전트와 호환

## Loop 관점 발췌
- loop·자율 반복·하네스 검증에 대한 구체 내용은 본 페이지에 없음 (설치 가이드 위주)

## loop.md 적용 가능 지점
- 직접 적용 없음. "Skills 표준 호환" 트렌드의 한 사례로만 기록.
