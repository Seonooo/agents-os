== Overview

MVP 게시판 API. 인증 없음. 모든 응답은 JSON. 에러 응답은 단일 계약(`ErrorResponse`)을 따른다.

* 기본 호스트: `http://localhost:8080`
* Content-Type: `application/json`

== Error contract

검증 실패(`VALIDATION_FAILED`)와 자원 없음(`RESOURCE_NOT_FOUND`)은 모두 `ErrorResponse` 형식.

```json
{
  "code": "VALIDATION_FAILED",
  "message": "Request validation failed",
  "path": "/posts",
  "timestamp": "2026-05-16T...",
  "errors": [
    {"field": "title", "message": "must not be blank"}
  ]
}
```

* `code` — `ErrorCode` enum 이름
* `message` — 사람용 메시지
* `path` — 요청 path (query string 제외)
* `timestamp` — 응답 생성 시각 (ISO-8601 UTC)
* `errors` — 검증 실패 시만. 그 외엔 생략(`@JsonInclude(NON_NULL)`)
