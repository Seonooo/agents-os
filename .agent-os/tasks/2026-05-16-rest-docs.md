# Task Context

## Goal

Spring REST Docs를 도입해 기존 **29개 E2E 테스트 모두**로부터 API 문서 스니펫을 자동 생성한다. Tests-as-docs 원칙 — 테스트가 검증하는 모든 관찰 가능 동작은 문서화 가치가 있다. 향후 endpoint·테스트가 추가될 때 동일 컨벤션 적용.

## Background

POST `/posts` 작업(2026-05-15)의 Q6 결정에서 "REST Docs 스니펫 작성 금지 — 별도 작업으로 분리" 로 미뤄둔 항목. 이번이 그 explicit task.

- MVP CRUD 5개 endpoint(POST·GET list·GET-by-id·PUT·DELETE)와 29개 E2E 테스트 완료된 시점.
- `spring-boot-starter-restdocs` + `spring-restdocs-mockmvc`는 init 시점부터 classpath에 있음.
- 사용자 검토에서 scope를 "5 happy paths"에서 "모든 29 E2E 테스트"로 확장(.review.md §2 🔴 Major correction).

## Existing Patterns

POST/GET/PUT/DELETE 모든 컨벤션 그대로 유지:
- `.claude/rules/conventions.md` 항목 전부 적용
- Testcontainers Postgres E2E 셋업
- ErrorResponse / ErrorCode 계약 불변

신규 패턴 (이번 도입):
- `@AutoConfigureRestDocs` 클래스 어노테이션 + `andDo(document(...))` 메서드 호출
- 스니펫 ID 컨벤션: **`post-{action}-{case}`** (예: `post-create-happy`, `post-create-missing-author`, `post-list-paginated`)
- AsciiDoc 소스는 `src/main/asciidoc/index.adoc` (Spring 관례)
- 스니펫 출력은 `build/generated-snippets/` (build.gradle.kts에 이미 설정)
- `ErrorResponse` 필드 descriptor는 `errorResponseFields()` private static helper로 재사용 (16개 error 테스트에서 호출)
- index.adoc 구조: `== {endpoint}` 헤더 + `=== {case}` 서브헤더 + snippet include 묶음

## Change Scope

Can change:

- `PostControllerE2ETest.java` — 클래스에 `@AutoConfigureRestDocs` 추가, **29개 테스트 메서드 각각에 `andDo(document(...))` 호출 추가**, `errorResponseFields()` private static helper 추가. **기존 assertion·메서드 시그니처는 그대로 유지** (추가만, 변경 없음).
- `src/main/asciidoc/index.adoc` — 신규 파일
- `build.gradle.kts` — asciidoctor plugin (`org.asciidoctor.jvm.convert` v4.0.5) + bootJar/asciidoctor 태스크 wiring 추가

Do not change:

- 모든 controller·service·repository·domain 파일
- DTO·response·error 계약 (시그니처·필드 불변)
- 기존 29개 테스트의 기존 assertion 본문 (오직 `andDo(document(...))` *추가* 만 허용)
- application.yml, hard-rules.md 잠금 파일들
- 새 testImplementation 의존성 추가 없음 (REST Docs는 이미 있음)
- 새 endpoint 신설 금지

## Constraints

- **Security**: 문서에 PII·시크릿·내부 stack trace 노출 금지. fixtures `alice/bob/Hello/World` 그대로.
- **Performance**: `document(...)` 호출은 테스트 실행 시간에 거의 영향 없음. 29 호출 누적도 무시 가능.
- **Operations**: 스니펫은 빌드 산출물. CI에서 `./gradlew test`로 자동 생성, `./gradlew asciidoctor`로 HTML 생성.
- **Compatibility**: 기존 38개 테스트 그대로 통과. assertion 본문 불변.
- **Time**: 학습 일정 내.

## Acceptance Criteria

### 스니펫 생성 — 29개 디렉터리
`./gradlew test` 실행 후 `build/generated-snippets/<snippet-id>/` 에 다음 29개 디렉터리 모두 존재:

**POST `/posts` (7)**
- `post-create-happy`, `post-create-missing-author`, `post-create-whitespace-title`, `post-create-missing-content`, `post-create-oversized-author`, `post-create-oversized-title`, `post-create-oversized-content`

**GET `/posts` (7)**
- `post-list-empty`, `post-list-multi-ordered`, `post-list-paginated`, `post-list-negative-page`, `post-list-size-zero`, `post-list-size-over-max`, `post-list-non-numeric-page`

**GET `/posts/{id}` (4)**
- `post-get-happy`, `post-get-not-found`, `post-get-negative-id`, `post-get-non-numeric-id`

**PUT `/posts/{id}` (7)**
- `post-update-happy`, `post-update-not-found`, `post-update-missing-title`, `post-update-whitespace-title`, `post-update-oversized-title`, `post-update-missing-content`, `post-update-oversized-content`

**DELETE `/posts/{id}` (4)**
- `post-delete-success`, `post-delete-not-found`, `post-delete-twice`, `post-delete-soft-excluded-from-list`

### 각 스니펫 내용
- `http-request.adoc`, `http-response.adoc` — 항상 생성
- `request-fields.adoc` — POST, PUT 요청 (body 있음)
- `response-fields.adoc` — happy paths + error responses (모두)
- `path-parameters.adoc` — GET-by-id, PUT, DELETE
- `request-parameters.adoc` — GET list (R7)
- `response-headers.adoc` — `post-create-happy` (Location 헤더)

### `errorResponseFields()` 공유 helper
- PostControllerE2ETest 내부 `private static ResponseFieldsSnippet errorResponseFields()` 정의
- 16개 error 테스트(POST 6 + PUT 6 + 4 not-found = 16)가 동일 helper 호출

### AsciiDoc 소스 — endpoint별 그룹 구조
- `src/main/asciidoc/index.adoc` 존재
- 5개 endpoint 각각이 `==` (level-2) 헤더로 시작
- 각 endpoint 내부에 케이스별 `===` (level-3) 서브섹션
- 각 서브섹션에 해당 스니펫의 `http-request`, `http-response`, 관련 fields/parameters `include::{snippets}/<id>/...[]`

### HTML 출력
- `./gradlew asciidoctor` 실행 → `build/docs/asciidoc/index.html` 생성
- 브라우저로 열어 29개 케이스가 endpoint별로 그룹화된 가독 가능한 형태로 표시

### 회귀
- 기존 38개 테스트 모두 그대로 통과 (assertion 변경 없음, `andDo(document(...))` *추가* 만 했으므로)
- field descriptor mismatch가 새 실패를 만들지 않음

## Forbidden

- 새 testImplementation 의존성 추가 금지 (REST Docs 이미 있음)
- endpoint 시그니처 변경 금지 (PostController·PostService·Repository 모두)
- `PostResponse`/`PostCreateRequest`/`PostUpdateRequest`/`PageResponse`/`ErrorResponse` 필드 추가·변경 금지
- 기존 38개 테스트의 assertion 본문 변경 금지 (`andDo(document(...))` *추가* 만 허용)
- `ErrorResponse` 형식 변경 금지
- 별도 doc-only 테스트 클래스 신설 금지 (기존 PostControllerE2ETest 확장)
- 새 endpoint 신설 금지
- `application.yml`의 잠금 키 변경 금지
- 스니펫 ID에 한국어·공백·특수문자 사용 금지 (`post-{action}-{case}` 영문 케밥-케이스만)
- field descriptor에 PII·시크릿 예시 사용 금지
